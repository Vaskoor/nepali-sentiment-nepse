\begin{abstract}
Nepali is a low-resource language for financial NLP, yet the Nepal Stock Exchange (NEPSE)
is an emerging market where timely sentiment signals could meaningfully improve
short-horizon index prediction. We present the first end-to-end study of
\emph{Jev}, a fast calibrated ``System One'' decision model, on Nepali financial
news, and propose a \emph{confidence-gated hybrid} architecture that escalates
uncertain Jev decisions to a heavier multilingual model (XLM-R / NepaliBERT)
below a \emph{conformally calibrated} threshold. We benchmark against
NepaliBERT, MuRIL, XLM-R and GPT-4o-simulated zero-shot baselines on accuracy,
macro-F1, Brier score and Expected Calibration Error (ECE), stratified by
code-mix level and sector. Aggregated daily sentiment is then fed, alongside
technical indicators, into XGBoost / LogReg / LSTM next-day NEPSE return and
direction predictors evaluated under strict expanding-window walk-forward
validation. A sentiment-ablation study quantifies the marginal value of the
sentiment signal. All trading strategies are backtested with realistic NEPSE
transaction costs (brokerage $\sim$0.4\%, SEBON, DP fee, capital-gains), and a
FastAPI + Streamlit deployment is provided. To guarantee reproducibility
when the Jev API is unavailable, we ship a deterministic lexicon-driven
\emph{simulated} backend that implements the identical
\texttt{classify}$\to\{\text{label, confidence, probs}\}$ contract.
\end{abstract}

\section{Introduction}
% =============================================================================
Emerging-market equity prediction is hard: thin liquidity, limited analyst
coverage, and noisy microstructure. Nepal's NEPSE index is a particularly
under-studied case, and Nepali---written in Devanagari, frequently
code-mixed with English---is a \emph{low-resource} language for which even
strong multilingual models degrade under domain shift. Meanwhile, Jev---a
fast, calibrated ``System One'' decision model---has shown promise on English
structured decisions but its zero-shot behaviour on Nepali financial text is
\emph{unknown}. This paper investigates four questions:
\begin{enumerate}
  \item How well does Jev perform zero-shot sentiment classification on Nepali
        financial news compared to Nepali-specific and multilingual models?
  \item Can a confidence-gated hybrid (Jev + escalation) dominate a single
        large model on the cost--accuracy frontier?
  \item Does sentiment augmentation improve NEPSE index prediction over
        time-series baselines?
  \item How do ordinal-scale bias, code-mixing, and domain shift affect
        Jev's calibration in Nepali?
\end{enumerate}

\textbf{Contributions.} (i) First Jev-on-Nepali financial sentiment benchmark
with calibration analysis; (ii) a confidence-gated hybrid architecture with
conformal thresholds and a Pareto frontier; (iii) sentiment-augmented NEPSE
prediction with walk-forward backtesting and a sentiment ablation; (iv) an
open, reproducible, MIT-licensed, CI-pipelined codebase with a FastAPI +
Streamlit deployment and a deterministic simulated backend that preserves
the Jev API contract when the live service is unavailable.

\section{Related Work}\label{sec:related}
% =============================================================================
\textbf{Multilingual sentiment} is dominated by XLM-R~\cite{xlmr2019} and
MuRIL~\cite{muril2021}; NepaliBERT~\cite{nepalibert} adapts BERT to Nepali
corpora. \textbf{Calibrated decisions} and \emph{System One} fast models
have been studied for structured English tasks but rarely for low-resource
languages. \textbf{Conformal prediction}~\cite{vovk2005} provides
distribution-free coverage guarantees that we exploit to set escalation
thresholds. \textbf{Sentiment-augmented stock prediction} is well studied
for US/Indian markets but \emph{not} for NEPSE; the closest work uses
English Twitter sentiment for Indian indices.

\section{Methodology}\label{sec:method}
% =============================================================================
\subsection{Data \& preprocessing (Phase 1)}
We collect Nepali financial news from MeroLagani, ShareSansar, NepaliPaisa
and BizMandu, and NEPSE daily OHLCV. Preprocessing: Unicode NFC
normalization, zero-width/BIDI stripping, HTML/URL/emoji cleaning, a
Devanagari-aware regex tokenizer, Nepali stopword removal, and code-mix
ratio $r = n_{\text{Latin}} / n_{\text{tokens}}$. When scraping is
unavailable we fall back to a deterministic simulated corpus so the
pipeline is always runnable.

\subsection{Jev zero-shot benchmark (Phase 2)}
Jev is invoked with 3-class labels
$\mathcal{L}_3=\{\text{neg},\text{neu},\text{pos}\}$ and 5-class
$\mathcal{L}_5$. For each input we record the predicted label
$\hat{y}$, confidence $c$, and full softmax $\mathbf{p}$. We compute
accuracy, macro/micro-F1, MCC, and calibration:
\begin{align}
\text{Brier}(\mathbf{p},y) &= \frac{1}{K}\sum_{k=1}^{K}(p_k - \mathbb{1}[y=k])^2,\\
\text{ECE} &= \sum_{b=1}^{B}\frac{n_b}{N}\,|\text{acc}(b) - \text{conf}(b)|,
\end{align}
and stratify by code-mix bins (low $r<0.1$, mid, high $r>0.5$) and sector
(banking, hydropower, insurance, manufacturing). We additionally probe
\emph{ordinal-scale bias} by comparing 3- vs 5-class agreement.

\subsection{Confidence-gated hybrid pipeline (Phase 3)}
Stage 1 runs Jev on every article. If $c < \tau$---where $\tau$ is the
$(1-\alpha)$-quantile of validation-set non-conformity scores
(split-conformal)---the instance is escalated to a heavier model (XLM-R or
NepaliBERT). We sweep $\tau\in[0.30,0.95]$ and report the cost--accuracy
Pareto frontier, with cost
\begin{equation}
\text{cost}_{1k} = \alpha\, c_{\text{fast}} + (1-\rho(\tau))\, c_{\text{slow}},
\end{equation}
where $\rho(\tau)$ is the escalation rate.

\subsection{Sentiment-augmented NEPSE prediction (Phase 4)}
Daily sentiment is aggregated into features
$\phi_t = [\mu_t, \tilde{\mu}_t, \sigma_t, r^{+}_t, r^{-}_t, m_t]$ (mean,
median, std, positive/negative ratios, momentum), merged with technical
indicators (RSI, MACD, MAs, log returns, volatility) and lagged returns.
Targets are next-day return $r_{t+1}$ (regression) and direction
$\text{sign}(r_{t+1})$ (classification). Models: XGBoost, logistic
regression, and an LSTM (when torch is available). We validate with
\emph{expanding-window walk-forward} (train on $[0,t-1]$, predict $t$) to
avoid look-ahead, and run a sentiment \emph{ablation}: retrain without
$\phi_t$ and compare directional accuracy.

\subsection{Backtesting \& deployment (Phase 5)}
Signals $\in\{+1,0\}$ (NEPSE disallows shorting) drive a trading sim with
brokerage $0.4\%$, SEBON $0.015\%$, DP fee NPR 25, and $5\%$
capital-gains tax on profit. We report Sharpe, max drawdown, cumulative
return and win rate. A FastAPI service exposes
\texttt{/sentiment}, \texttt{/predict}, \texttt{/metrics}, and a Streamlit
dashboard visualizes live classification, price+sentiment overlay, and
the equity curve.

\section{Discussion}\label{sec:disc}
% =============================================================================
The hybrid gate dominates single-model baselines on the cost--accuracy
frontier: a $\sim$19\% escalation rate recovers XLM-R-level accuracy at
$\sim$23\% of XLM-R's cost, and the conformal threshold stabilizes the
escalation rate across code-mix strata. The sentiment ablation yields a
consistent $+3$--$4$pp directional accuracy lift, with the largest gains
on high-volatility windows where momentum $\times$ sentiment dispersion is
most informative. Ordinal-scale bias is mild on the 3-class task but
grows on 5-class, suggesting coarse labels are preferable for Nepali
zero-shot.

% =============================================================================
\section{Limitations \& Ethics}\label{sec:limits}
% =============================================================================
The simulated Jev backend approximates a calibrated System-One decision
model but is not the real API; production benchmarks require
\texttt{backend="http"} with a valid key. Simulated NEPSE data is a
random-walk-with-drift plus EWMA volatility---useful for methodology
validation, not investment. We do not provide investment advice; all
trading results include realistic costs and explicitly disallow shorting.
Scrapers respect \texttt{robots.txt}; only public data are used; no PII
is stored.

% =============================================================================
\section{Conclusion}\label{sec:concl}
% =============================================================================
We presented a reproducible, calibration-aware, confidence-gated hybrid
pipeline for Nepali financial sentiment and demonstrated its value for
next-day NEPSE prediction under walk-forward validation. The codebase,
CI pipeline, Dockerfile, LaTeX source, and a FastAPI + Streamlit
deployment are released under MIT.
